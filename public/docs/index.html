Before you copy anything

Open My Hub → Sandbox companies. Copy the number shown below the company name.

02

Security rule

Keep every secret out of view

Never share

Client Secret, tokens, OAuth codes, cookies, MFA QR codes, and one-time codes.

Paste only here

Wrangler's hidden prompt or a Cloudflare field explicitly marked Secret.

Keep the token key

Do not replace QB_TOKEN_KEY after connecting. Existing ciphertext requires it.

If exposed

Revoke the credential at its provider and create a replacement immediately.

05

Operator boundary

Protect QuickBooks controls

  1. Enable email login

    In Cloudflare Zero Trust, open Settings → Authentication → Login methods and enable One-time PIN.

  2. Create the Pages Access policy

    Open Workers & Pages → fox-referrals → Settings, select Enable access policy, and manage the generated application.

  3. Narrow the protected path

    In Zero Trust → Access controls → Applications, change *.fox-referrals.pages.dev to fox-referrals.pages.dev and set the path to /api/quickbooks/*.

  4. Allow one operator

    Use a 15-minute session, an Allow policy for the operator email, and independent MFA.

  5. Enroll MFA

    Open the App Launcher, then Account → MFA devices → Add an MFA device. Choose Authenticator application.

Direct MFA enrollment
https://YOUR-TEAM.cloudflareaccess.com/AddMfaDevice
Webhook exceptionCreate one exact Access bypass.

Use fox-referrals.pages.dev/api/quickbooks/webhook with a Bypass policy for Everyone. Do not use a wildcard. The Worker still rejects requests without Intuit's HMAC.

Add the Access values to Worker configuration

ACCESS_TEAM_DOMAINhttps://YOUR-TEAM.cloudflareaccess.com
ACCESS_AUDOperator app Audience tag
ACCESS_ADMIN_SUBOperator sub / user_uuid

CheckpointThe claim page is public. The status page requires OTP and MFA. Webhook GET returns 405; an unsigned webhook POST returns 400.

06

Provider setup

Configure the Intuit development app

  1. Select the app

    Open developer.intuit.com → My Hub → Workspaces. Create or select an app with QuickBooks Online accounting access. Stay on Development.

  2. Copy the Company ID

    Open My Hub → Sandbox companies. Copy the numeric ID below the company name into QB_REALM_ID.

  3. Collect credentials

    Open Keys & Credentials → Development. Reveal the Client ID and Client Secret. Keep both private.

07

Encrypted configuration

Store the four Worker secrets

Run one command at a time. Paste each value only when Wrangler displays its hidden prompt.

PowerShell
npx.cmd wrangler secret put QB_CLIENT_ID --config wrangler.worker.jsonc
npx.cmd wrangler secret put QB_CLIENT_SECRET --config wrangler.worker.jsonc
npx.cmd wrangler secret put QB_WEBHOOK_VERIFIER --config wrangler.worker.jsonc
node scripts/set-token-key.mjs

The last command creates and uploads QB_TOKEN_KEY without printing it. Change QB_ENABLED to true, then deploy.

Enable the integration
npx.cmd wrangler deploy --config wrangler.worker.jsonc

CheckpointAll four secrets exist in the Worker. Their values do not appear in source, configuration, terminal history, or screenshots.

08

OAuth

Authorize the correct Sandbox company

Protected URLhttps://fox-referrals.pages.dev/api/quickbooks/connect
  1. Pass Access

    Sign in with the allowed email, email OTP, and enrolled MFA method.

  2. Start authorization

    Select Authorize sandbox company.

  3. Choose the company

    In Intuit, select the company whose ID matches QB_REALM_ID, then select Connect.

  4. Confirm the result

    Back on the operator page, check the company name and ID, then select Confirm sandbox company.

Expected status: active

It must not include (paused). A commission with status PENDING is recorded but unpaid; it does not mean OAuth is pending.

Safe connection check
npx.cmd wrangler d1 execute fox-referrals --remote --config wrangler.worker.jsonc --command "SELECT state,realm_id,paused,token_version,(token_envelope IS NOT NULL) AS has_encrypted_tokens FROM qb_connection WHERE id=1"

10

When a screen does not match

Troubleshooting index

No authentication methods set upCloudflare Access

Select Setup MFA or open the direct /AddMfaDevice URL and enroll an authenticator application.

Welcome! No applications are availableCloudflare Access

Enable the Access App Launcher for the operator email, enroll MFA, then return to the protected operator URL.

INVALID_ORIGINOperator page

Reopen /api/quickbooks/connect and use the button on the fresh page. Do not open the form action directly or resubmit a stale page.

QUICKBOOKS_NOT_CONFIGUREDWorker

Check every required non-secret variable and all four Worker secrets. Do not print their values.

Wrong company or IDIntuit

The App ID was probably copied into QB_REALM_ID. Use the ID shown under Sandbox companies.

refresh_unknown (paused)OAuth safety hold

Disconnect the app from the Sandbox company and follow the technical recovery procedure. Never edit stored tokens or expiry values.

The claim rejects my phoneClaim page

The current product accepts US/NANP numbers only. Use the documented synthetic US number for testing.

Shop Genie openedExpected behavior

The claim succeeded. Shop Genie is Fox's real public booking page. Stop there during the synthetic test.

No webhook event appearedIntuit webhook

Wait at least five minutes, then check the exact endpoint, Access bypass, verifier, CloudEvents setting, and Invoice/Payment subscriptions. Do not force database rows.
